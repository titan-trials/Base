## What changed, by severity

**S1 — deployed ≠ validated.**
The K prop now compounds `per_batter_k_probs` (hitter 600-PA odds ratio ×
pitcher 12-month shrunk odds × measured platoon factor) instead of the
hitter LR's career-window pitcher input. `backtest_k_props.py` runs the
deployed path, rolling origin, 2,834 starts Apr–Aug 2026: **+0.094 (over
5.5), +0.097 (over 6.5)**, calibrated within 1 pt, every month positive.
Thin pitchers now get new-pitcher priors (≈21.0 BF, lower K rate) and are
excluded from the market edge list. PA projection is an empirical
P(PA | slot, home) table (`EmpiricalPAModel`) replacing the skewed
regression; spread 1.14 → 1.03, level matches the pool's own history.

**S2 — biased.**
Starter share is per pitcher and per slot from the workload model's BF
distribution (exact mod-9 arithmetic), exported as `starter_share`. Team
model scales lineup sums by the measured 7.9% bench run share; home-field
run gap is measured/printed but not applied (would double-count `is_home`);
`score_slate.score_teams` grades win prob + totals, logs
`team_scoring_log.csv`, compares to `gamelines_{date}.csv` when fetched
(`python -m data.odds_lines DATE gamelines`, 2 credits). ATH park factor
fixed (was routed to the Coliseum).

**S3 — small correctness.**
Tonight's features now include the hitter's last PA (`add_tonight_rows`);
pitcher rolling rates ordered within game; PA definition whitelisted
(`truncated_pa`, baserunning events out; `strikeout_double_play` in) and
verified to 0.006 PA/game against boxscores; OBP / RBI / RBI-model inputs
shrunk.

**Flags (default off) — `model_flags.py`, `flag_lab.py`.**
LOGIT_FEATURES: real, negligible (+0.0003). PLATOON_SPLIT, trailing league
prior: negligible. PITCHER_RATE_WINDOW_DAYS=365: is_k BETTER +0.0007,
walks −0.0003. **PER_HITTER_SHAPE: TB over 0.5 +0.0069, 1.5 +0.0022,
3.5 +0.0017, CIs exclude 0 — the one worth turning on.**
